# Deskly

Aplicación destinada a la gestión de centros de Coworking

## Tecnologías
- Backend: NestJS
- Mobile: React Native / Expo
- Database: PostgreSQL
- Documentation: Swagger
- Package Manager: pnpm

## Arquitectura
- Monorepo
- Modular backend
- Mobile-first
- Escalable a microservicios

## Estructura
/backend
/mobile
/docs

## Instalación Backend
cd backend
pnpm install
pnpm start:dev

## Instalación Mobile
cd mobile
pnpm install
pnpm start
