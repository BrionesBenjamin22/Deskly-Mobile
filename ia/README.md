# Conversaciones por entrega y funcionalidad

Este directorio organiza las conversaciones del proyecto por entrega y por
funcionalidad. Los archivos `CONVERSACION.md` se conservan como bitácoras
acumulativas e históricas; los archivos temáticos permiten localizar una
solicitud sin recorrer toda la conversación.

## Entregas

- [Entrega 1](entrega-1/README.md): base técnica, escritorios y reservas MVP.
- [Entrega 2](entrega-2/README.md): autenticación, roles y operación.
- [Entrega 3](entrega-3/README.md): ubicaciones, pagos, seguridad,
  infraestructura y performance.

## Contenido obligatorio

Cada conversación temática registra, cuando existe evidencia:

1. solicitud y objetivo;
2. funcionalidades realizadas;
3. decisiones y contratos;
4. bugs o diagnósticos;
5. resultados y observaciones;
6. validación automática y manual;
7. pendientes transferidos;
8. mensaje de commit propuesto.

No se incluyen secretos ni se presentan como ejecutadas pruebas que no estén
respaldadas por la bitácora, las tareas o la documentación del repositorio.
